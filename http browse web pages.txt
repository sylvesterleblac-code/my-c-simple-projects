http verbs
http requests begin with a verb like: 
GET - fetch a document.
POST - submit a form
HEAD - fetch metadata about a document 
PUT - upload a file
http headers have a key followed by a colon follwed by a value eg key: value
example is: 
nc google.com 80
GET / HTTP/1.0
Host: google.com
NB: make sure to hit 'return' twice after the 'Host: google.com'
the 'host: google.com' is the header
you can also send http requests with the curl command:
curl -s http://subastack.net
curl -I -s http://substack.net - this will only print out the headers
this is helpful when you want to debug a server that you are working on
use '-X' to set the http verb (eg POST) and '-d' to set form parameters
